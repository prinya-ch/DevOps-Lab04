# DevOps-Lab04 — DRILL OPS

## คำอธิบายโครงการ

DRILL OPS เป็นหน้าเว็บต้นแบบสำหรับศูนย์ฝึกซ้อมของทีม IT Support และ Service Desk ช่วยให้ทีมเลือกสถานการณ์จำลอง วางแผนรอบฝึก และฝึกการสื่อสารกับการแก้ไขปัญหาอย่างเป็นระบบ ก่อนนำแนวทางไปใช้กับเหตุการณ์จริง

หน้าเว็บเป็นภาษาไทย ออกแบบให้ใช้งานได้ทั้งบนคอมพิวเตอร์และอุปกรณ์หน้าจอขนาดเล็ก และรวม HTML, CSS และ JavaScript ไว้ในไฟล์เดียว

## ความสามารถ

- แสดงภาพรวมและรายการสถานการณ์ฝึกซ้อม เช่น ปัญหาเครือข่าย บัญชีผู้ใช้ และอุปกรณ์
- กรองรายการสถานการณ์ตามประเภท
- เปิดแบบฟอร์มเริ่มซ้อมเพื่อเลือกทีมและบทบาท
- แสดงตารางรอบฝึกซ้อม พร้อมปุ่มลงชื่อหรือยกเลิกการลงชื่อ
- แสดงข้อความยืนยันการทำรายการบนหน้าเว็บ
- แสดงขั้นตอนการฝึกซ้อม ตั้งแต่เลือกสถานการณ์ ซ้อมร่วมกัน จนถึงทบทวนผล

## วิธีเปิดใช้งาน

ไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์ เพียงเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์รุ่นปัจจุบัน

## เทคโนโลยี

- HTML สำหรับโครงสร้างและเนื้อหา
- CSS สำหรับรูปแบบและการปรับหน้าจอตามอุปกรณ์
- JavaScript สำหรับตัวกรอง แบบฟอร์ม หน้าต่างโต้ตอบ และข้อความแจ้งเตือน

## ข้อจำกัด

โครงการนี้เป็นต้นแบบฝั่งหน้าเว็บ การเริ่มสถานการณ์และการลงชื่อเข้าร่วมเป็นการจำลองเพื่อแสดงผลเท่านั้น ข้อมูลไม่ได้ถูกบันทึกหรือส่งไปยังระบบหลังบ้าน และปุ่มเข้าสู่ระบบยังแสดงข้อความแจ้งเตือนแทนการยืนยันตัวตนจริง

หน้าเว็บโหลดแบบอักษรจาก Google Fonts และภาพพื้นหลังจาก Unsplash หากไม่มีอินเทอร์เน็ต เนื้อหาและฟังก์ชันหลักยังเปิดได้ แต่อาจใช้แบบอักษรสำรองและไม่แสดงภาพพื้นหลัง
